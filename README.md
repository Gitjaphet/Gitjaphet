## Modules Odoo 19 — Hôtellerie et restauration

| Module | Description |
|---|---|
| **[POS_HOTEL_INTC](https://github.com/Gitjaphet/POS_HOTEL_INTC)** | Gestion hôtelière : consommations du POS transférées sur la chambre, folio, check-in / check-out, fiche de police, night audit comptable |
| **[pos_hotel_amenities](https://github.com/Gitjaphet/pos_hotel_amenities)** | Produits d'accueil des chambres, débités du stock automatiquement au ménage |
| **[pos_customer_account_intc](https://github.com/Gitjaphet/pos_customer_account_intc)** | Clients en compte au restaurant : relevé du dû (ticket ou PDF) et facture regroupée après règlement |

Chaque module est déployé automatiquement sur le serveur à chaque `push` (GitHub Actions).
